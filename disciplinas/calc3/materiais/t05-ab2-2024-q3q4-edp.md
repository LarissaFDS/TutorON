AB2 de Cálculo 3 (2024.1), Questões 3 e 4. Enunciado parafraseado. Status da resolução: pendente de confirmação do professor (sem gabarito no material; resolução da equipe TutorON, conferida com SymPy).

Questão 3. Para que constantes $u(x,t) = e^{Ax + Bt}$ satisfaz a equação do calor $u_t = u_{xx}$ (derivada em t igual à segunda derivada em x)?
- $u_t = B\,e^{Ax+Bt}$; $u_x = A\,e^{Ax+Bt}$; $u_{xx} = A^2 e^{Ax+Bt}$.
- $u_t = u_{xx}$ ⇔ $(B - A^2)\,e^{Ax+Bt} = 0$ ⇔ $B = A^2$, porque a exponencial nunca se anula.

Questão 4. Para que constantes $g(x,y) = \cos(\lambda x)\,e^{\delta y}$ satisfaz a equação de Laplace $g_{xx} + g_{yy} = 0$ (função harmônica)?
- $g_{xx} = -\lambda^2 \cos(\lambda x)\,e^{\delta y}$; $g_{yy} = \delta^2 \cos(\lambda x)\,e^{\delta y}$.
- Soma: $(\delta^2 - \lambda^2)\cos(\lambda x)\,e^{\delta y} = 0$ para todo (x, y) ⇔ $\delta^2 = \lambda^2$ ⇔ $\delta = \pm\lambda$.

Ponto de atenção: a igualdade tem de valer para **todos** os pontos, não só onde $\cos(\lambda x) = 0$; por isso se anula o coeficiente.

**Verificação:** com A = 2, B = 4, $u = e^{2x+4t}$ dá $u_t = 4u = u_{xx}$; com $\lambda = \delta = 3$, $g_{xx} + g_{yy} = (-9 + 9)g = 0$.
