Nota da equipe TutorON sobre vetores (Halliday, cap. 3). Leitura indicada: OpenStax University Physics, vol. 1, cap. 2.

Componentes de um vetor de módulo a com ângulo θ medido a partir do semieixo +x, no sentido anti-horário: $a_x = a\cos\theta$ e $a_y = a\,\text{sen}\,\theta$. Módulo: $a = \sqrt{a_x^2 + a_y^2}$. Ângulo: $\tan\theta = a_y/a_x$, olhando o quadrante (a calculadora devolve o mesmo arctan para (1, 1) e (−1, −1)).

Soma: componente a componente. Exemplo: $\vec a = (3{,}0;\ 4{,}0)$ m e $\vec b = (-1{,}0;\ 2{,}0)$ m dão $\vec a + \vec b = (2{,}0;\ 6{,}0)$ m, módulo ≈ 6,3 m e ângulo ≈ 71,6°.

Produto escalar: $\vec a \cdot \vec b = a_x b_x + a_y b_y = a b\cos\phi$. No exemplo: −3 + 8 = 5 m², e $\cos\phi = 5/(5 \times 2{,}236)$ → φ ≈ 63,4°.

**Verificação:** $\sqrt{2^2 + 6^2} = \sqrt{40}$ ≈ 6,32; arctan(6/2) ≈ 71,6°; o produto escalar positivo concorda com φ < 90°.
