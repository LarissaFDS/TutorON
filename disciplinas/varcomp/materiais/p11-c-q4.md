Como calcular a integral de z² (∫ z² dz) ao longo de um segmento de reta, de 0 até 2 + i: integral complexa sobre caminho aberto, com primitiva ou com parametrização.

Integrando $f(z) = z^2$ (z ao quadrado), sobre o segmento de reta de $z = 0$ a $z = 2 + i$.

**Por primitiva (independência do caminho):** $z^2$ é inteira e tem primitiva $F(z) = z^3/3$ em todo o plano, então a integral só depende dos extremos:
$$\int_\gamma z^2\,dz = F(2 + i) - F(0) = \frac{(2 + i)^3}{3}.$$
$(2 + i)^2 = 3 + 4i$; $(3 + 4i)(2 + i) = 6 + 3i + 8i - 4 = 2 + 11i$. Resultado: $\frac{2 + 11i}{3} = \frac23 + \frac{11}{3}i$.

**Pela parametrização (confere):** $\gamma(t) = (2 + i)t$, $0 \le t \le 1$, $dz = (2 + i)\,dt$: $\int_0^1 (2 + i)^2 t^2\,(2 + i)\,dt = (2 + i)^3\int_0^1 t^2 dt = (2 + i)^3/3$. Mesmo resultado.

O resultado seria o mesmo por qualquer outro caminho de 0 a $2 + i$, porque $z^2$ é analítica (Cauchy-Goursat). Isso **não** vale para $\bar z$ ou $|z|^2$, que não são analíticas.

**Verificação:** integração numérica do segmento parametrizado dá $\approx 0{,}6667 + 3{,}6667i$; SymPy integra $(2 + i)^3 t^2$ de 0 a 1 e confere.
